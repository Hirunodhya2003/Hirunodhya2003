## 🚀 Featured Cloud & DevOps Projects

### ☁️ [Terraform AWS Three-Tier Architecture](https://github.com/Hirunodhya2003/aws-three-tier-infrastructure)
`Terraform` `AWS VPC` `ALB` `EC2` `RDS MySQL`

Infrastructure as Code for a multi-AZ AWS network with public and private subnets. A private EC2 backend sits behind an internet-facing Application Load Balancer, with a private RDS MySQL database. Chained security groups restrict traffic between each tier, and credentials are kept out of version control.

---

### 🔄 [Employee Management DevOps Project](https://github.com/Hirunodhya2003/Employee-management-devOps)
`Jenkins` `Docker Compose` `AWS EC2` `Nginx` `Prometheus` `Grafana` `React` `Spring Boot` `MySQL`

A full-stack CRUD application deployed to AWS EC2 with Docker Compose. A Jenkins pipeline triggered by GitHub webhooks automates build, test, Docker image creation and deployment. Includes an Nginx reverse proxy, persistent MySQL storage, and Prometheus/Grafana monitoring. Credentials are secured with Jenkins credentials and environment variables.

---

### 🛒 [Azure Three-Tier E-Commerce Platform](https://github.com/Hirunodhya2003/Azure-ecomerce-platform) *(in progress)*
`Azure` `Docker` `Azure Container Registry` `Prometheus` `Grafana` `React` `Spring Boot`

A React frontend, Spring Boot REST API and MySQL database in a three-tier design. The backend is containerized and its versioned image is published to Azure Container Registry, with Prometheus and Grafana JVM dashboards.
**Next up:** Terraform-managed Azure infrastructure and a GitHub Actions CI/CD pipeline.
